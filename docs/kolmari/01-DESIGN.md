# Kolmari Design System and Brand Identity

## Identity (locked)

- Kolmari is a relocation decision system, not a vacation, booking, or generic travel product.
- Kolmari helps people evaluate relocation, choose a viable place, build a plan, and act.
- Tone is direct, practical, informed, confident, and human.
- Avoid generic SaaS language and aspirational filler.

## Approved product lexicon

| Approved term | Meaning | Primary placement |
|---|---|---|
| **Kolmari** | The platform for international relocation planning | Brand and identity |
| **Your World** | The global map and discovery interface | Map title and navigation |
| **Destination** | A country or region being evaluated | Cards and detail pages |
| **Kolmari Profile** | User inputs (income, work, family, timing, lifestyle) | Onboarding and sidebar |
| **My Plan** | The user's structured relocation plan | Dashboard |
| **Match Score** | Compatibility between a profile and a destination | Destination cards |
| **Pathways** | Applicable visa and residence options | Wizard and destination detail |
| **Move Readiness** | The user's current preparation level | Dashboard and score UI |
| **Move Timeline** | Relocation actions organized over time | Plan view |
| **Greenbook Insights** | Sourced lived-experience and context summaries | Destination pages |
| **Community Fit** | A qualitative belonging and daily-life consideration | Cards and Greenbook Insights |
| **Flutter Mode** | The transition from research to execution | Primary dashboard action |
| **Progress Tracker** | Checklist and progress system | Dashboard and tracker |
| **Kolmari Klub** | The community of people planning relocation | Community section |

## Visual system

### Palette

| Token | Value | Role |
|---|---|---|
| Navy | `#17305B` | Primary headings, ink, branded surfaces |
| Deep Navy | `#0D1B39` | Darkest surfaces, sidebar, hero |
| Gold | `#F3C516` | Primary actions, active progress, emphasis |
| Canvas | `#F4F6F9` | Light app background |
| White | `#FFFFFF` | Cards |
| Slate / Muted | `#6B7A92` | Secondary text |
| Cloud Border / Line | `#E7EBF1` | Dividers, card borders |
| Teal | `#1F9D94` | Community and Greenbook meaning |

### Typography

- **Geist Sans:** all product UI, navigation, controls, labels, body
- **Playfair Display:** selective editorial headlines only
- **Geist Mono:** technical values only

### Primary visual symbol

The butterfly is the primary visual symbol of Kolmari. Do not add decorative butterfly language throughout the interface. Use it with restraint at intentional brand moments.

## Do not use

- "Nexit", "Nexitnation", "Nextination", "Nexicution", "Nexiter" in public UI
- Generic travel-product language ("journey", "destination" for a vacation concept)
- Fabricated scores, Match Scores, or readiness values
