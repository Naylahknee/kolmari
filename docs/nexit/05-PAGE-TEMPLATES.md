# Nexit Page Templates

Each page template defines the information that must be visible immediately, the information that may use progressive disclosure, and the action the page should support.

## 21. Country Page Templates

### Overview

Purpose: provide an executive summary.

Include:

- Why this country matched
- Important tradeoff
- Country snapshot
- Language
- Currency
- Climate
- Population
- Common destination cities
- Suggested first actions
- What this country may offer you
- What may require adjustment

Use document-style headings, dividers, compact tables, and checklists.

### Economic Profile

Purpose: set the stage for reality.

Include:

- GDP and GDP per capita
- Growth trend
- Inflation trend
- Unemployment rate
- Currency stability
- Purchasing power
- Typical wages
- Minimum wage
- Rent-to-income pressure
- Major industries
- Growing sectors
- Major employers
- Startup activity
- Tourism dependence
- Regional economic differences

Required section:

```text
What this economy may mean for you
```

Interpretation must be based on the user's profile and clearly separated from raw data.

Every metric must show:

- Source
- Reporting period
- Last verified date

## 22. Dashboard Home

The Dashboard should feel like a calm workspace home, not a dense analytics dashboard.

### Header

```text
Welcome back, [First Name]
Continue planning your Nexit.
```

### Default dashboard sections

Show no more than four primary sections initially:

1. Continue where you left off
2. Your Nextinations
3. Your Nexit Plan
4. Recent activity

### Continue where you left off

Show:

- Nextination
- Last viewed section
- Last activity time
- Continue action

### Your Nextinations

Use a compact table or gallery:

| Nextination | Match | Pathway | Status |
|---|---:|---|---|
| Portugal | 88% | Remote Work | Researching |
| Spain | 84% | Remote Work | Comparing |
| Costa Rica | 81% | Digital Nomad | Saved |

Only display real user-generated results.

### Your Nexit Plan

Show:

- completion progress
- next task
- deadline or timing when available
- resume plan action

### Recent activity

Show only meaningful actions:

- saved a Nextination
- compared countries
- completed the public quiz
- reviewed a Pathway
- uploaded a document

### Nexit Pathways directory template

The full Pathways page must not render every category fully expanded.

Required order:

1. Page title and plain-language disclaimer
2. Personalized summary, when real profile data exists
3. Category filters
4. Top three compact pathway matches
5. `Explore all Pathways` accordion directory
6. Sources and legal disclaimer

The highest-ranked category opens by default. Each summary card includes only the information needed to choose whether to inspect details.

Every expanded pathway includes:

- overview
- intended applicant
- Pathway Match
- core and financial requirements
- documents
- dependents
- work rights
- application stages
- processing estimate
- renewal
- permanent-residence potential
- risks or limitations
- official sources and last verification

Approved labels:

- Likely fit
- Possible fit
- More information needed
- Unlikely based on current answers

Never state that the user qualifies or is guaranteed approval.

### Nexit Plan template

Nexit Plan is an operational workspace, not an article.

Visible header:

- plan name
- selected Nextination and Pathway
- target date
- progress
- current phase
- next recommended action

Phase groups:

- Research
- Pathway selection
- Application preparation
- Visa application
- Pre-departure
- Arrival
- First 30 days
- Long-term settlement

The active phase opens by default. Accordion headers show phase status and task count. Tasks remain checkable without expanding long descriptions. Detailed task instructions open inline or in a side panel.

### Cost Calculator template

The calculator is a tool surface.

Keep visible:

- city, household, and budget inputs
- estimated monthly total
- budget difference
- housing share
- emergency buffer

Use expandable sections for category assumptions and methodology. On desktop, the result summary may be sticky. On mobile, results appear before detailed breakdowns.

### Documents template

Visible:

- readiness summary
- missing and urgent items
- expiration warnings
- upload action

Accordion groups:

- Identity
- Civil records
- Financial
- Employment
- Education
- Healthcare and insurance
- Dependents
- Visa-specific
- Housing
- Pets

Each header shows completion and warning counts.

### Nexitnation template

Nexitnation remains visual and map-led. Do not convert it into an accordion feed.

Use:

- illustrated discovery map or Mapbox as defined by context
- region filters
- featured and saved Nextinations
- detail drawer

The detail drawer may use accordions for cost, Pathways, community, climate, and regional context while keeping the map visible.

### Comparison template

Primary comparison data must remain visible in a side-by-side matrix. Accordions may hold supporting notes but must not hide core differences.

### Dashboard template

Show no more than four primary blocks:

1. Continue where you left off
2. Your Nextinations
3. Your Nexit Plan
4. Recent activity

Do not add accordions unless recent or archived items exceed a reasonable length.
# 23. Comparison Workspace Template

Do not use accordions for the main comparison data.

Use a structured comparison layout.

## Required structure

```text
Selected Nextinations
Comparison controls
Category matrix
Key differences
Tradeoffs
Save comparison
```

Compare:

* Nexit Match
* economic profile
* cost
* housing
* Pathways
* healthcare
* education
* transportation
* Greenbook
* legal and tax context

Use accordions only for detailed notes beneath each comparison category.
